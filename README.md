# jetty — NMU Campus Marketplace

**Jetty** is the campus marketplace for **Nigeria Maritime University (NMU)**, covering both **Okerenkoko** and **Kurutie** campuses in Delta State. Students can discover cadet gear, safety boots, action rigs, electronics, books, student housing/bedspaces, and campus services—and message verified vendors directly on WhatsApp without creating an account.

## Brand Assets (`/public`)
- `/jetty-mark.svg` — Primary brand mark (pier-shaped J + gold wave)
- `/jetty-favicon.svg` — Simplified favicon mark (for sizes ≤ 32px)
- `/jetty-icon-192.png`, `/jetty-icon-512.png`, `/jetty-icon-512-maskable.png` — PWA icons
- `/manifest.json` — Web App Manifest (`theme_color: #0F6E6E`)

## Brand Color Tokens
- `--jetty-teal: #0F6E6E` (Primary buttons, mark background)
- `--jetty-teal-deep: #0A4F4F` (Hover/pressed states, dark surfaces)
- `--jetty-teal-tint: #E6F2F2` (Subtle backgrounds, chips)
- `--jetty-gold: #E8B84A` (Accents, highlights, badges)
- `--jetty-ink: #0E1B1B` (Primary text on light)
